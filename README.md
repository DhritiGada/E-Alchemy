# E-Alchemy

E-Alchemy is an academic learning and planning project that evolved from a PHP/MySQL e-learning platform into an interactive semester-planning prototype.

**Live planner:** https://e-alchemy-planner.vercel.app/

## E-Alchemy Planner

The new planner helps students build a more sensible semester based on completed coursework, prerequisites, workload, credit targets, and academic focus.

### Features

- Degree progress tracking
- Completed-course simulation
- Prerequisite-aware recommendations
- Focus areas: Balanced, AI & Data, Product, Systems
- Adjustable semester credit target
- Workload scoring
- Editable semester plan
- Explainable course recommendations
- Prerequisite-lock indicators
- Responsive React interface

## Original project

The original E-Alchemy application is preserved in this repository. It was built as a PHP/MySQL e-learning platform with:

- User registration and login
- Course catalog
- Course enrollment
- Student dashboard
- Lectures and course details
- Admin functionality
- Relational MySQL data model

## Planner tech stack

- React
- Vite
- JavaScript
- Lucide React
- CSS
- Vercel

The planner source lives in `/planner`.

## Run the planner locally

```bash
cd planner
npm install
npm run dev
```

Then open the local Vite URL shown in your terminal.

## Note

The planner is a product prototype for academic planning and does not replace official academic advising.
